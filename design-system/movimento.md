# Movimento

## Linha do tempo da vinheta

| Tempo | Evento |
|---|---|
| 0,0–0,5s | Frasco surge em fade (opacidade 0 → 100%) |
| 0,5–2,0s | Frasco flutua levemente |
| 2,0s | Tampa salta para cima e para a direita |
| 2,3–4,5s | Frasco inclina ~45°, cápsulas caem e quicam, formando o chão |
| 5,5s | Frasco sobe e some em fade |
| 5,8–6,5s | Letras de PÍLULAS DO sobem uma a uma |
| 6,3–7,0s | Letras de CONHECIMENTO sobem em cascata da esquerda para a direita |
| 7,0s | Barra cresce do centro para as bordas |
| 7,5s | Subtítulo entra em fade |
| 8,0–10,0s | Brilho percorre o título; chão de pílulas estático |

## Movimento em slides

- Transição entre slides: **Esmaecer** 0,3s. Entre módulos: **Empurrar** para a esquerda 0,5s.
- Tópicos: entrada **Flutuar para dentro** de baixo, 0,2s cada, em sequência.
- Barra de progresso: **Limpar** da esquerda, 0,4s.
- Nada de girar, quicar, zoom exagerado ou efeito de máquina de escrever.
