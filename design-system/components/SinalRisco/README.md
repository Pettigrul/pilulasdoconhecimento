# SinalRisco

Etiqueta de classificação para achados e riscos em aulas de auditoria. Adição intencional: não existe na vinheta.

- Sempre com a palavra escrita; a cor sozinha não carrega o significado.
- Use `sinal-critico` para alto, `sinal-atencao` para médio e `destaque` para controle efetivo ou risco baixo.
