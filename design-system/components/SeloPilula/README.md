# SeloPilula

Selo em forma de cápsula com o número à esquerda (azul) e o rótulo à direita (branco).

- Use no canto superior esquerdo da capa e dos divisores para dizer qual pílula ou módulo é.
- Número sempre com dois dígitos (01, 02) ou código de módulo (M1, M2).
- Rótulo curto, no máximo três palavras.
