# Assinatura

A assinatura completa da série: sobretítulo PÍLULAS DO, nome CONHECIMENTO, barra-assinatura e a linha Auditoria Interna | Banco BV.

- Use só na capa, no encerramento e em materiais de divulgação. Nos slides internos use o RodapeSlide.
- Sempre sobre o fundo radial do palco (`.pc-palco` ou a imagem fundo-palco). Nunca sobre fundo claro.
- O tamanho da assinatura inteira é controlado pelo `font-size` do contêiner `.pc-assinatura`: ele é o tamanho do nome; sobretítulo, barra e subtítulo escalam juntos.
- Em PowerPoint ou Canva, prefira a imagem `lockup-pilulas-do-conhecimento.png` do grupo Marca.
- Não trocar a ordem das metades da barra (azul à esquerda), não remover o brilho, não recolorir o nome.
