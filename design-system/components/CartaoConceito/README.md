# CartaoConceito

Caixa para um conceito, uma etapa ou um item de comparação.

- Forneça rótulo curto (caixa alta), título de até duas linhas e texto de até três linhas.
- Use de dois a quatro cartões lado a lado. Com mais que isso, divida em dois slides.
- Apenas um cartão por slide recebe `.pc-cartao--realce`: o que você quer que a turma lembre.
