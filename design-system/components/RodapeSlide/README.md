# RodapeSlide

Faixa de rodapé com a assinatura em texto, a barra de progresso e a paginação.

- Posição: base do slide, dentro da margem de segurança (96px laterais, 48px da base).
- Não aparece na capa nem no encerramento, que já têm a assinatura completa.
- Paginação com dois dígitos ("04 / 10").
